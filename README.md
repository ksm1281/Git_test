# ERP/CRM

Система управління підприємством та взаємовідносинами з клієнтами.

## Функціонал

- **Дашборд** — статистика, останні замовлення, залишки, швидкі дії
- **Склад** — облік товарів, рух складу, корекція залишків
- **Прихідні накладні** — створення, підтвердження, історія постачань
- **Постачальники** — управління контрагентами
- **Ціноутворення** — націнки (опт/дрібний опт/роздріб), індивідуальні ціни
- **Замовлення** — перегляд замовлень з OpenCart, аналіз прибутку
- **Клієнти** — база клієнтів, нотатки, історія замовлень
- **Повернення** — реєстрація, схвалення, обробка, повернення на склад
- **Аналітика** — графіки доходу та замовлень, топ постачальники
- **Персонал** — управління користувачами та ролями (admin/manager/staff)

## Вимоги

- PHP 8.0+
- MySQL 5.7+ / MariaDB 10.3+
- PDO MySQL extension

## Встановлення

1. Створіть базу даних MySQL
2. Налаштуйте підключення в `config.php`:
   - `DB_HOST` — хост бази даних
   - `DB_USER` — ім'я користувача
   - `DB_PASS` — пароль
   - `DB_NAME` — назва бази даних
3. Відкрийте `login.php` у браузері

### Перший вхід

- **Логін:** `admin`
- **Пароль:** `admin`

Таблиці створюються автоматично при першому завантаженні.

## Інтеграція з OpenCart

Система підтримує синхронізацію з OpenCart. Налаштування API в `config.php`:

- `OC_API_URL` — URL API OpenCart
- `OC_API_KEY` — ключ API

## Валюти

- Базова валюта закупівель: USD
- Валюта продажів: UAH
- Автоматичний курс з API ПриватБанку
- Ручне встановлення курсу

## Ролі

| Роль | Права |
|---|---|
| **admin** | Повний доступ, управління персоналом |
| **manager** | Схвалення/обробка повернень, корекція складу |
| **staff** | Перегляд, створення документів |
